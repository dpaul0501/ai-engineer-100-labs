03 / EXACT

First solve it for 100 users

The exact algorithm reveals the right data structures.
Pseudocode → Python
from collections import Counter

def suggest(graph, u, k=10):
    direct = set(graph[u])
    count = Counter()
    for friend in direct:
        for v in graph[friend]:
            if v != u and v not in direct:
                count[v] += 1
    return sorted(count, key=lambda v:
        (-count[v], v))[:k]
Walkthrough
D1 mutual
E2 mutual
F1 mutual

Result: E, D, F (ties resolved by ID).

DSA: adjacency list + hash set + frequency map + top-k.

W(u) = Σf ∈ N(u) degree(f)

Expected traversal: O(W). Full sort of C distinct candidates: O(C log C).

06 / BUDGET

Replace unbounded exploration with a candidate budget

Approximation is a product decision with measurable fidelity.
Budgeted candidate generation
def candidate_pool(graph, user, budget=5000):
    direct = set(graph[user])
    score = Counter()
    for f in ordered_friends(user):
        for v in bounded_neighbors(f):
            if eligible(user, v) and v not in direct:
                score[v] += 1
            if visits_exceeded(budget):
                return score
    return score

Pseudocode: friend ordering, bounded sampling, and visit accounting require implementation choices.

07 / APPROX

Three ways to reduce work—and what each gives up

Choose approximations according to the query.
A. Sample / cap neighbors
01

Explore a subset of friends or high-degree neighbor lists.

Work ≈ O(B)

Trade-off: potentially miss relevant two-hop links.

Evaluate: candidate recall, degree bias.

B. MinHash / LSH
02

Represent neighbor sets with signatures; propose pairs with high estimated Jaccard similarity.

J(A,B) = |A∩B| / |A∪B|

Trade-off: signature error / missed candidates.

Evaluate: recall vs index size and build cost.

C. Graph embeddings / ANN
03

Learn user vectors; retrieve nearby vectors through an approximate index.

similarity(u,v) = u · v

Trade-off: learned similarity and approximate index recall.

Evaluate: recall, latency, downstream quality.

A sketch such as Bloom filter can accelerate set-membership checks, but it does not directly compute exact mutual-friend counts or solve candidate ranking.
